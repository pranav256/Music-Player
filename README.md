# Desktop Music Player

A desktop audio player with dual frontends written in PyQt5 and Tkinter with custom styling.

## Features

- **Audio Playback:** Play, pause, resume, stop, and volume slider controls via `pygame.mixer`.
- **Playlist Management:** Browse local directory folders, import `.mp3` and `.wav` tracks, and manage queue.
- **Dual UI Implementations:** Explores Tkinter themed widgets alongside PyQt5 stylesheets.

## Tech Stack

- Python 3.8+
- PyQt5 & Tkinter
- Pygame Audio Mixer (`pygame`)

## Run

```bash
pip install PyQt5 pygame ttkthemes
python main.py
```
